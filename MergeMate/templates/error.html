How to start MongoDB on Windows:

  1. Start MongoDB Windows Service:
    Open Command Prompt (or PowerShell) as Administrator and run: 
    net start MongoDB
  2. Or check Windows Services GUI:
    Press Win + R, type services.msc, locate MongoDB Server (MongoDB), and click Start.
  3. Verify MongoDB Connection:
    By default, MongoDB Community Server runs locally at mongodb://127.0.0.1:27017/ with no username or password required.
  4. Initialize Indexes & Sample Data:
    In your project directory, execute: 
    python database/setup_indexes.py
python database/sample_data.py
